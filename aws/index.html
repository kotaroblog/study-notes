オンプレ経験者のための AWS 図解

見えるAWS

AWS の基本の部品を1つずつ足しながら、Web アプリの構成図ができていく様子を見ます。各ステップで「何を足したか」「オンプレだと何に当たるか」「料金がかかるところ」を確かめます。

オンプレから来た人が押さえる3つの違い

ここだけ先に押さえると、下の図が読みやすくなります。

違い 1

「買う」ではなく「借りる」

使った時間や量だけ料金がかかります。置いてあるだけで料金がかかるもの（NAT ゲートウェイ、パブリック IPv4 アドレス、停止中の EC2 のディスクなど）もあるので、使い終わったら消します。

違い 2

障害への強さは「置き方」で決まる

AWS に置けば自動で冗長化されるわけではありません。2つ以上のアベイラビリティゾーン（AZ）に分けて置く構成にして、初めて障害に強くなります。

違い 3

ネットワークも権限も、全部「設定」

ケーブルや機器の代わりに、VPC・ルートテーブル・セキュリティグループ・IAM の設定で決まります。設定の誤りが、そのまま穴になります。

場面1：Web アプリを1つ AWS に載せる

何もない状態から部品を1つずつ足して、よくある構成（ロードバランサー＋2台のサーバー＋データベース）を作ります。
