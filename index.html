見える学習ノート

コマンドや仕組みの「動き」を、1ステップずつ図で追うための学習ノートです。

  • 見えるGit SVN 経験者向け

    コマンド1つで、ファイルとブランチが作業フォルダ・ステージ・ローカル・リモートのどこへ動くか。

    • 場面1：機能ブランチを作って、main に入るまで（15ステップ）

  • TypeScript 隙間ドリル JS・Swift 経験者向け

    1単元5〜9分の問題で、型の考え方を Swift と比べながら身につける。問題のコードはすべて実際の tsc で確かめ済み。

    • 全14単元・77問（基本の型・union・null・ジェネリクス・Promise・モジュールなど）

  • 見えるAWS オンプレ経験者向け

    AWS の基本の部品を1つずつ足しながら、Web アプリの構成図ができていく様子と、リクエストの通り道を見る。

    • 場面1：Web アプリを1つ AWS に載せる（15ステップ）
